# Remotion source reference

`src/video10/` contains the episode-specific React/Remotion source for the
final film and scene studies, including the veto, map odds, roster sensitivity
and side-by-side contender sequences. `FinalFilm.tsx` is the final picture
composition in the original workspace.

These files are an archival code reference, not a ready-to-render project.
They refer to the original workspace's shared components, timeline and media
configuration, licensed fonts, footage, images and narration. Those inputs
are intentionally not distributed. The standalone forecast checker does not
depend on the production source.
